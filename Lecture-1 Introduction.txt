Django:-
-------------
>> It is not a programming language , It is a framework in which you can develop Web Application only.
>> It support MVT architecture.
Model. -> DAL (Data Access Layer.) -> In it , we perform all database related Operations.
View. -> BLL (Business Logic Layer.)
>> In it , we write main logic of our program.
>> It is the heart of Django , it interact both model and template.
Template. -> PLL (Presentation Logic Layer.)
>> It is the UI [User Interface] of our program. (html , css , js etc.)
